# Agent Hub

ממשק מקומי בעברית לניהול משימות, שיוך ידני של סוכנים, שאלות ואישורים. מרכז ההחלטות מותאם למחשב ול־Android.

המאגר הציבורי מכיל קוד מוצר נקי בלבד. הגדרות המשתמש, מפתחות, מסדי נתונים, דוחות מקומיים והיסטוריית הפיתוח הפרטית אינם חלק ממנו. אין כרגע Release ציבורי להתקנה; פרסום עתידי יכלול EXE ו־APK לאחר אישור בעל הפרויקט.

## הפעלה מהקוד

נדרשים Python 3.11 ומעלה וחיבורי הסוכנים המקומיים. התקינו את `requirements.txt` בסביבה וירטואלית. העתיקו `worker.example.json` לקובץ המקומי המוחרג `worker.local.json`, והגדירו בו נתיבי ריפוזיטוריז, סוכנים ונתיב מסד נתונים במחשב שלכם.

הפעלת הווב: `python local_app.py --config worker.local.json`. הממשק נקשר ל־127.0.0.1 בלבד. לחלופין השתמשו ב־`start-local.cmd` וב־`stop-local.cmd` לאחר יצירת `.venv`.

גישה מהטלפון דורשת שרת HTTPS פרטי דרך Tailscale, זהות משתמש מורשית ב־`tailnet` והמשך פעילות המחשב. אין לפרסם את שרת ה־HTTP ישירות לאינטרנט.

## Android

המקור נמצא ב־`android/`. הבנייה משתמשת ב־JDK 17, Gradle 9.5, Android Gradle Plugin 9.3 ו־SDK 37.1. הריצו `gradle :app:testDebugUnitTest :app:lintDebug :app:assembleDebug` מתוך התיקייה.

האפליקציה משתמשת באותו שרת ובאותן אפשרויות של הווב. במסך הראשון מזינים את כתובת ה־HTTPS הפרטית. מעטפת ה־Android חוסמת גישה לקבצים, תוכן מקומי, תעודות לא תקינות ומשאבים מחוץ לשרת הנבחר. קישור לעדכון ציבורי נפתח בדפדפן רק בלחיצת המשתמש.

## היקף העבודה וההרשאות

המשתמש משייך סוכן ראשי אחד לכל משימה. החלפת מבצע זמינה כשהמשימה בתור. משתתפים נוספים הם נתוני תיאום בלבד ואינם מקבלים הרשאות לתפוס משימה או לקרוא הקשר של סוכן אחר. מפעיל הסוכנים מיועד לקריאה בלבד; אישור בתוך Hub אינו מחליף אישור מקורי של ספק הכלי.

קראו את `AGENT-HUB-PROMPT.he.md` לפני חיבור סוכן. אין להפעיל את מסלול MCP הישיר ואת מסלול worker במקביל באותה זהות.

## בדיקות וגרסאות

בדיקות שרת: `python -m unittest discover -s tests`. בדיקת דפדפן עם מסד זמני וללא worker: `python tests/serve_ui_fixture.py` (פורט 8891). נתוני בדיקה אינם משימות אמיתיות.

`version.json` הוא מקור מספר הגרסה; `CHANGELOG.md` מסכם שינויים, ו־`VERSIONING.md` מגדיר את נוהל הגרסאות. כפתור בדיקת העדכון פונה ל־Release הציבורי האחרון בלבד ואינו מתקין תוכנה.
