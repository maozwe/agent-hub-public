# Agent Hub

ממשק מקומי בעברית לניהול משימות, שיוך אוטומטי לסוכן פנוי או שיוך ידני, שאלות ואישורים. מרכז ההחלטות מותאם למחשב ול־Android.

המאגר הציבורי מכיל קוד מוצר נקי בלבד. הגדרות המשתמש, מפתחות, מסדי נתונים, דוחות מקומיים והיסטוריית הפיתוח הפרטית אינם חלק ממנו. אין כרגע Release ציבורי להתקנה; פרסום עתידי יכלול EXE ו־APK לאחר אישור בעל הפרויקט.

## הפעלה מהקוד

נדרשים Python 3.11 ומעלה וחיבורי הסוכנים המקומיים. התקינו את `requirements.txt` בסביבה וירטואלית. העתיקו `worker.example.json` לקובץ המקומי המוחרג `worker.local.json`, והגדירו בו נתיבי ריפוזיטוריז, סוכנים ונתיב מסד נתונים במחשב שלכם.

הפעלת הווב: `python local_app.py --config worker.local.json`. הממשק נקשר ל־127.0.0.1 בלבד. לחלופין השתמשו ב־`start-local.cmd` וב־`stop-local.cmd` לאחר יצירת `.venv`.

גישה מהטלפון דורשת שרת HTTPS פרטי דרך Tailscale, זהות משתמש מורשית ב־`tailnet` והמשך פעילות המחשב. אין לפרסם את שרת ה־HTTP ישירות לאינטרנט.

## Android

המקור נמצא ב־`android/`. הבנייה משתמשת ב־JDK 17, Gradle 9.5, Android Gradle Plugin 9.3 ו־SDK 37.1. הריצו `gradle :app:testDebugUnitTest :app:lintDebug :app:assembleDebug` מתוך התיקייה.

האפליקציה משתמשת באותו שרת ובאותן אפשרויות של הווב. במסך הראשון מזינים את כתובת ה־HTTPS הפרטית. מעטפת ה־Android חוסמת גישה לקבצים, תוכן מקומי, תעודות לא תקינות ומשאבים מחוץ לשרת הנבחר. קישור לעדכון ציבורי נפתח בדפדפן רק בלחיצת המשתמש.

## Windows והתראות בגרסה 0.3.0

בנייה מקומית: התקינו גם `windows/requirements.txt` ו־Inno Setup 6, ואז `python windows/build.py --iscc "path/to/ISCC.exe"`. המתקין בתיקיית `dist/`, למשתמש הנוכחי וללא Python במחשב היעד. הנתונים נשמרים ב־`%LOCALAPPDATA%/AgentHub`, בנפרד מההתקנה; הסרה משאירה אותם. אין התקנה אוטומטית בהפעלת Windows.

המשגר פותח את הווב בדפדפן. ניתן לפתוח Hub קיים ב־8876 או שרת בדיקה מבודד ב־8892. ייבוא הגדרות משאיר את מסד הנתונים נפרד ומסיר הגדרות Tailscale; הסוכנים אינם מופעלים אוטומטית. להפעלתם דרושים הכלים וההרשאות המקומיים הרגילים.

התראות Windows ניתנות להפעלה במשגר ונמשכות כל עוד חלונו פתוח או ממוזער. סגירתו מפסיקה את התראות המחשב; שרת הבדיקה נעצר בכפתור מפורש. התראות כפופות להגדרות Windows ומצב ריכוז.

פוש Android הוא אופציונלי: הורידו את תצורת אפליקציית Firebase ל־`android/firebase.local.json` (מוחרג מ־Git). הגדרת השרת המקומית דורשת `firebase` עם `project_id` ו־`credentials` כנתיב לקובץ service account מקומי בעל הרשאת שליחת FCM בלבד. מפתחות פרטיים אינם נכללים בקוד או במתקינים. ללא תצורת Firebase, Android נבנה ללא חיבור לפוש.

לאחר התקנת APK וחיבור לשרת HTTPS פרטי, לחצו במסך ״שרת״ על ״הפעלת התראות פוש״ ואשרו הרשאת Android. ניתן לכבות באותו מקום. רישום מכשיר דורש חיבור פרטי ואימות CSRF. Firebase מקבל token של המכשיר והודעה כללית בלבד, ללא טקסט/מזהה משימה, שאלה או אישור. אין Analytics. לחיצה פותחת את מרכז ההחלטות; הפרטים נטענים מהשרת הפרטי.

השרת צריך לפעול כדי לזהות אירועים ולשלוח פוש. התראות מאוחדות על שאלות/אישורים חדשים, חסימות וסיומים; אין השלמת התראות היסטוריות בזמן שהשרת היה כבוי. Android עשוי לעכב התראות לפי הרשאות, רשת וחיסכון בסוללה. עצירה כפויה של האפליקציה דורשת פתיחה מחדש. בדיקת הפצה אמיתית חייבת לכלול מכשיר פיזי.

## היקף העבודה וההרשאות

המשתמש משייך סוכן ראשי אחד לכל משימה. החלפת מבצע זמינה כשהמשימה בתור. משתתפים נוספים הם נתוני תיאום בלבד ואינם מקבלים הרשאות לתפוס משימה או לקרוא הקשר של סוכן אחר. מפעיל הסוכנים מיועד לקריאה בלבד; אישור בתוך Hub אינו מחליף אישור מקורי של ספק הכלי.

קראו את `AGENT-HUB-PROMPT.he.md` לפני חיבור סוכן. אין להפעיל את מסלול MCP הישיר ואת מסלול worker במקביל באותה זהות.

## בדיקות וגרסאות

בדיקות שרת: `python -m unittest discover -s tests`. בדיקת דפדפן עם מסד זמני וללא worker: `python tests/serve_ui_fixture.py` (פורט 8891). נתוני בדיקה אינם משימות אמיתיות.

`version.json` הוא מקור מספר הגרסה; `CHANGELOG.md` מסכם שינויים, ו־`VERSIONING.md` מגדיר את נוהל הגרסאות. כפתור בדיקת העדכון פונה ל־Release הציבורי האחרון בלבד ואינו מתקין תוכנה.

## Local voice drafts

Install requirements, then download the Whisper model once with `python -c "from faster_whisper import WhisperModel; WhisperModel('small', device='cpu', compute_type='int8')"`. Voice recordings (90 seconds maximum) are transcribed on the Hub computer and are not saved. Review and edit the transcript before submitting. No Ollama text-model connection is used. Android microphone support requires app version 0.12.0 or later.
